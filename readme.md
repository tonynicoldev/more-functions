# JavaScript Functions
This demo covers a number of aspects of JavaScript functions

## Arrow functions
The same function is written three times using a named function, an anonymous function and an anonymous arrow function to compare the syntax

It goes on to illustrate how arrow functions can be written differently depending on the number of lines of code in the body or the number of parameters

## callback1
This demonstrates a higher order function - i.e., a function where a function is passed as an argument to the higher-order function. The passed-in function is a callback function as the higher-order function calls it

## callback2
This demo illustrates an asynchronous callback being passed to a higher-order function as an argument. Unlike the previous example, this callback is not called until an asynchronous activity has completed

## returnValue
This demo shows an object being returned to illustrate how to return more than one value from the function


Note: there is no need for nom or express for these demos as they are purely JavaScript functions running in node
